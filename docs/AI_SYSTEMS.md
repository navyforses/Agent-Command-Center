## 1. NEXUS OMEGA - მრავალ-AI კვლევის ორქესტრატორი

### რა არის NEXUS?

NEXUS არის "გროვის ინტელექტის" (Swarm Intelligence) სისტემა, რომელიც ერთდროულად იყენებს 5 AI აგენტს სამედიცინო კვლევისთვის. თითოეულ აგენტს აქვს უნიკალური როლი და სპეციალიზაცია.

### AI აგენტები

| აგენტი | როლი | სპეციალიზაცია |
|--------|------|---------------|
| **Claude** | მთავარი ანალიტიკოსი & ეთიკის მცველი | ღრმა ანალიზი, ბალანსირებული მსჯელობა |
| **GPT-4** | კრეატიული პრობლემების გადამჭრელი | კროს-დომენური სინთეზი, კრეატიული კავშირები |
| **Grok** | რეალ-ტაიმ ინტელექტი & კონტრარიანი | უჩვეულო პერსპექტივები, ტრენდების პროგნოზი |
| **Gemini** | მულტიმოდალური მკვლევარი | აკადემიური სიზუსტე, მეტა-ანალიზი |
| **Perplexity** | წყაროების მაძიებელი & ფაქტების შემმოწმებელი | ციტირება, ბიბლიოგრაფია |

### ძირითადი ფუნქციები

1. **Swarm Debate** - აგენტები "კამათობენ" და აანალიზებენ შეთანხმებებს/უთანხმოებებს
2. **ჰიპოთეზების გენერაცია** - ახალი კვლევითი ჰიპოთეზების შექმნა
3. **დისციპლინათაშორისი ანალიზი** - 30+ სამეცნიერო დისციპლინის პერსპექტივა
4. **კონსენსუსის დონეები** - დაბალი, საშუალო, მაღალი, ერთხმად

### კონსენსუსის დონეები

```
unanimous  - ყველა აგენტი თანხმდება (უმაღლესი სანდოობა)
high       - უმრავლესობა თანხმდება
moderate   - ზომიერი თანხმობა
low        - მნიშვნელოვანი უთანხმოება
```

### API Endpoints

```
GET  /api/nexus/ai-status         - AI აგენტების სტატუსი
POST /api/nexus/research          - კვლევის დაწყება
GET  /api/nexus/findings          - აღმოჩენების სია
GET  /api/nexus/hypotheses        - ჰიპოთეზები
GET  /api/nexus/debates           - დებატები
```

### გამოყენება UI-ში

NEXUS კომპონენტები:
- `DebatePanel.tsx` - დებატების პანელი

## 2. EVOLUTION - ციკლური სწავლის ძრავა

### რა არის EVOLUTION?

EVOLUTION არის ბიოლოგიური სწავლით შთაგონებული სისტემა, რომელიც 7 ფაზაში ციკლურად იკვლევს სამედიცინო მდგომარეობებს. თითოეული ციკლი რამდენიმე "დღეს" გრძელდება.

### 7 ფაზა

| ფაზა | ქართულად | ხანგრძლივობა | აღწერა |
|------|----------|--------------|--------|
| **observe** | დაკვირვება | 8 საათი | მონაცემების შეგროვება |
| **learn** | სწავლა | 4 საათი | პატერნების ამოცნობა |
| **connect** | დაკავშირება | 4 საათი | დისციპლინათაშორისი კავშირები |
| **theorize** | თეორიზება | 4 საათი | ჰიპოთეზების ფორმირება |
| **synthesize** | სინთეზი | 2 საათი | პრინციპების აბსტრაქცია |
| **validate** | ვალიდაცია | 2 საათი | ფაქტების შემოწმება |
| **adapt** | ადაპტაცია | 2 საათი | დახვეწა |

### ექსპერტ პერსონები

სისტემა იყენებს 8+ სპეციალიზებულ პერსონას:
- პედიატრიული ნევროლოგი
- ნეირორეაბილიტაციის სპეციალისტი
- კლინიკური გენეტიკოსი
- ნეიროფარმაკოლოგი
- ბიომედიცინური ინჟინერი
- ნეიროიმიჯინგის სპეციალისტი
- სარეაბილიტაციო მედიცინის ექსპერტი
- კვლევის კოორდინატორი

### შედეგების ტიპები (Insight Types)

```
observation  - დაკვირვება
pattern      - პატერნი
connection   - კავშირი
hypothesis   - ჰიპოთეზა
validation   - ვალიდაცია

```

### API Endpoints

GET  /api/evolution/reports                   - რეპორტები

## 3. PROMETHEUS - კოგნიტური მეხსიერების სისტემა

### რა არის PROMETHEUS?

PROMETHEUS არის თვითევოლუციონირებადი AI მეხსიერების სისტემა. ის სწავლობს Evolution ციკლებიდან, აშენებს ცოდნის გრაფს, აღმოაჩენს და ასწორებს შეცდომებს, და მუდმივად იხვეწება.

### მეხსიერების ფენები

| ფენა | ქართულად | აღწერა |
|------|----------|--------|
| **episodic** | ეპიზოდური | კონკრეტული მოვლენები/დაკვირვებები |
| **semantic** | სემანტიკური | ფაქტები, პრინციპები, კონცეფციები |
| **procedural** | პროცედურული | "როგორ" ცოდნა, პროცესები |
| **working** | სამუშაო | აქტიური მსჯელობა, დროებითი |
| **meta** | მეტა | ცოდნა სწავლის პროცესის შესახებ |

### სანდოობის დონეები

```
definite   - განსაზღვრული (მაღალი სანდოობა)
high       - მაღალი
moderate   - ზომიერი
low        - დაბალი
uncertain  - გაურკვეველი
```

### ძირითადი ფუნქციები

1. **ცოდნის გრაფი** - კვანძები და კავშირები კონცეფციებს შორის
2. **შეცდომების აღმოჩენა** - წინააღმდეგობები, დროითი შეცდომები
3. **თვით-კორექცია** - ავტომატური შეცდომების გასწორება
4. **კონსოლიდაცია** - "სიზმრის ფაზა" ცოდნის სინთეზისთვის
5. **მეტა-სწავლა** - მსჯელობის პროცესის გაუმჯობესება

### კონსოლიდაციის ციკლი

```
collection     → მონაცემების შეგროვება
evaluation     → მნიშვნელობის შეფასება
integration    → არსებულთან დაკავშირება
compression    → პრინციპებად აბსტრაქცია
reorganization → გრაფის ოპტიმიზაცია
pruning        → არავალიდურის წაშლა
```

### API Endpoints

```
GET  /api/prometheus/status/:childId          - სტატუსი
POST /api/prometheus/search                   - სემანტიკური ძიება
GET  /api/prometheus/predictions/:childId     - პროგნოზები
GET  /api/prometheus/notifications            - შეტყობინებები
GET  /api/prometheus/knowledge-graph/:childId - ცოდნის გრაფი
```

### გამოყენება UI-ში

კომპონენტები:
