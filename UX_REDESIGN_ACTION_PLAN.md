```
├── Secondary: outline სტილი
├── Ghost: გამჭვირვალე ფონი
└── ზომები: sm (32px), md (40px), lg (48px), xl (56px)

🧩 ბარათები (Cards)
├── ჩრდილი: subtle (0 1px 3px rgba)
├── Border radius: 16px
├── Padding: 20px (desktop), 16px (mobile)
└── Hover: ოდნავ აწევა (translateY -2px)

🧩 ფორმის ელემენტები
├── Input height: 48px (touch-friendly)
├── Label: ზემოთ, არა შიგნით
├── Error: წითელი border + შეტყობინება ქვემოთ
└── Focus: primary color ring

🧩 აიკონები
├── ბიბლიოთეკა: Lucide Icons
├── ზომა: 20px (default), 24px (emphasized)
└── სტილი: outline (არა filled)
```

### 4.4 მობილური ადაპტაცია:

```
📱 Breakpoints
├── Mobile: 0 - 639px
├── Tablet: 640px - 1023px
└── Desktop: 1024px+

├── Bottom navigation (არა sidebar)
├── Full-width buttons
├── Stacked layouts (არა grid)
├── Larger touch targets (min 44px)
```
