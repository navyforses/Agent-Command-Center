## დუბლიკატების პრობლემა და გადაწყვეტა

ერთი და იგივე კვლევა შეიძლება დარეგისტრირებული იყოს 3-4 რეესტრში. მაგალითად, დიდი საერთაშორისო კვლევა შეიძლება იყოს ClinicalTrials.gov-ზე, EU CTR-ზე და WHO ICTRP-ზე ერთდროულად.

**გადაწყვეტა:** თითოეულ კვლევას აქვს უნიკალური იდენტიფიკატორები (NCT ნომერი, EudraCT ნომერი, WHO ID). ვქმნით mapping table-ს და ვაერთიანებთ შედეგებს. როცა ერთი კვლევა რამდენიმე წყაროშია, ვაჩვენებთ ერთხელ, მაგრამ მივუთითებთ ყველა წყაროს.

## ტექნიკური სტეკი

```
Backend: Python (FastAPI)
├── Scrapers: BeautifulSoup, Selenium
├── APIs: httpx (async requests)
├── Database: PostgreSQL (Supabase)
├── Cache: Redis (duplicate detection)
├── AI: OpenAI GPT-4o API
└── Queue: Celery (background jobs)

Frontend: React + TypeScript
├── UI: Tailwind CSS
├── Search: Real-time autocomplete
└── Results: Interactive cards

Hosting: Replit (Deployments)
├── Backend: Always-on
├── Database: Supabase (external)
├── Cron: Daily data refresh
└── Cost: ~$25/month
```

## რას იძლევა ეს უნიფიკაცია
