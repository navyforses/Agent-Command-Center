## თარგმანის სტრატეგია

### ვარიანტი A: Real-time Translation (GPT-4o)

```
მომხმარებელი ეძებს → ინგლისურად ძიება → 
შედეგები ინგლისურად → GPT-4o თარგმანი → 
მომხმარებელს მის ენაზე

✓ უპირატესობა: ყოველთვის fresh, ყველა ენა მხარდაჭერილი
✗ მინუსი: ნელი (2-3 წამი), ძვირი (თითო request)
```

### ვარიანტი B: Pre-translated Cache

```
ყოველღამე batch job → ყველა ახალი კვლევა → 
GPT-4o თარგმნის TOP 10 ენაზე → 
ინახება database-ში → instant delivery

✓ უპირატესობა: სწრაფი, იაფი per-request
✗ მინუსი: cache size, ნაკლებად პოპულარული ენები real-time
```

### ჰიბრიდული მიდგომა (რეკომენდებული)

```
TOP 10 ენა (KA, HY, AZ, RU, UK, KK, UZ, BN, AM, TI):
→ Pre-translated cache
→ ყოველღამე განახლება
→ Instant delivery

დანარჩენი 30+ ენა:
→ Real-time GPT-4o
→ Cache after first request
→ 2-3 წამი დაყოვნება

სამედიცინო ტერმინები:
→ Custom glossary per language
→ Human review for accuracy
→ Community corrections
```

## მონაცემთა ბაზის სქემა

```sql
-- ენების ცხრილი
CREATE TABLE languages (
    code VARCHAR(5) PRIMARY KEY,      -- 'ka', 'hy', 'az'
    name_native VARCHAR(100),          -- 'ქართული'
    name_english VARCHAR(100),         -- 'Georgian'
    direction VARCHAR(3),              -- 'ltr' or 'rtl'
    tier INT,                          -- 1=pre-cached, 2=on-demand
    is_active BOOLEAN DEFAULT true,
    speakers_millions DECIMAL(10,2),
    diaspora_millions DECIMAL(10,2)
);

-- თარგმანების cache
CREATE TABLE trial_translations (
    id SERIAL PRIMARY KEY,
    trial_id VARCHAR(50),              -- NCT number
    language_code VARCHAR(5),
    title_translated TEXT,
    summary_translated TEXT,
    eligibility_translated TEXT,
    translated_at TIMESTAMP,
    translation_quality DECIMAL(3,2),  -- 0.00-1.00
    human_reviewed BOOLEAN DEFAULT false,
    
    UNIQUE(trial_id, language_code)
);

-- სამედიცინო გლოსარი
CREATE TABLE medical_glossary (
    id SERIAL PRIMARY KEY,
    term_english VARCHAR(200),
    language_code VARCHAR(5),
    term_translated VARCHAR(200),
    definition_translated TEXT,
    category VARCHAR(50),              -- 'disease', 'treatment', 'anatomy'
    verified BOOLEAN DEFAULT false,
    
    UNIQUE(term_english, language_code)
);

-- მომხმარებლის პრეფერენციები
CREATE TABLE user_preferences (
    user_id UUID PRIMARY KEY,
    primary_language VARCHAR(5),
    secondary_language VARCHAR(5),
    region VARCHAR(50),
    diagnosis_interests TEXT[],
    email_frequency VARCHAR(20)        -- 'daily', 'weekly', 'monthly'
);
```
